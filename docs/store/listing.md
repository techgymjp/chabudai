```
スマホを振り上げてちゃぶ台を飛ばせ！クルッと回って叫んで、砲丸投げの競技場で飛距離を競う体感ゲーム
```

**詳しい説明**

```
「こんな飯が食えるかぁ！」

かつて大ヒットしたスマホアプリ「ちゃぶ台返し」が、リメンバー版として帰ってきた！
スマホを思いきり振り上げて、ハゲ親父がちゃぶ台をひっくり返す。
飛んでいったちゃぶ台は、砲丸投げの競技場をどこまでも……。目指せ世界記録！

■ 体ごと使って、ちゃぶ台を返せ
・スマホを振り上げる勢い（加速度）と、手首のキレ（ジャイロ）
・砲丸投げのようにクルッと 1 回転すると、遠心力で記録アップ
・叫び声の大きさが「気合」になる（マイクで音量だけを測定）
・振り上げる角度で、ちゃぶ台の飛ぶ角度が決まる
・今年の恵方に向かって投げると、縁起ボーナス

■ 競技場を飛んでいくちゃぶ台
・ご飯、味噌汁、焼き魚、湯呑が宙を舞い、ガシャーンと割れる
・高く飛ぶほどカメラも空へ。追い風・向かい風も記録に影響
・正面からズレすぎると、まさかのファウル
・ごくまれに、ちゃぶ台ではなく親父が飛んでいく……

■ その他
・「ちゃぶ台を撫でただけ」から「伝説のちゃぶ台神」までの称号
・どのセンサーが弱かったか、結果画面でアドバイス
・自己ベストと称号を友だちにシェア
・センサーがない端末でも、タッチ操作で遊べる
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

※ スマホがすっぽ抜けないよう、しっかり握って遊んでください。周りに人や物がないか確認してから遊びましょう。
```

## Play Console「アプリのコンテンツ」の回答の目安

- **プライバシー ポリシー**: https://techgym.jp/privacy-policy/
- **広告**: 「はい、広告を含みます」
- **アプリのアクセス権**: 「制限なし（ログイン不要）」
- **広告 ID**: 「使用する」（目的は「広告またはマーケティング」と「アナリティクス」）
- **ターゲット ユーザー**: 13 歳以上（13 歳未満を含めると広告に制限がかかる）
- **データ セーフティ**: アプリ自体は個人情報を集めない。Google AdMob が「デバイスまたはその他の ID（広告 ID）」と「アプリの操作（広告の表示・クリック）」を広告とアナリティクスの目的で収集・共有する。通信は暗号化されている。
  マイクは叫び声の音量を端末内で測るだけで、録音・保存・送信はしない（端末から外に出ないデータは「収集」に当たらない）。※ AdMob の公式ガイドと Play のヘルプに従って最終確認すること
- **コンテンツのレーティング**: ゲーム → 暴力表現なし（ちゃぶ台や食器がひっくり返って割れる程度のコミカルな表現。人物のけが・流血なし）
